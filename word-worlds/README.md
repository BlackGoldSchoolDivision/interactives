# Word Worlds

An open-ended paper-theatre language playground. Students change a sentence, predict and observe a visual/audio interpretation, compare independent A/B versions, and explain their choices.

- 12 open challenges; town, woodland and harbour settings.
- 4 subjects, 8 verbs, 8 atmosphere words: 768 curated combinations across settings.
- Layered Canvas artwork, draggable camera, animated weather and foliage; motion pause and reduced-motion support.
- Opt-in Web Audio generated locally, plus optional device speech synthesis.
- Gallery and reflection retained in sessionStorage in this browser tab. No accounts, remote writing service, analytics or microphone.
- Comparison PDFs include actual scene snapshots and paginate long reflections. Blank paper experiment provided.
- Make it my own downloads a self-contained HTML with embedded fonts, artwork, scripts and licenses.

The scene is an authored interpretation, not an automatic evaluation of language or mood. Students can disagree with the interpretation and support their own reading. Keep this pair records an experiment without grading it. Suggested Grades 3–6+, flexible for discussion.

Serve the repository as static files. Open `/word-worlds/`. No build or runtime package install is required. Repository CI runs meaningful model and browser checks, actual touch input, the six required responsive viewports, offline exports, and PDF bounds verification. Checks for both language playgrounds live in `word-worlds/tools/`.

Created for Engaging Students / Black Gold School Division, October 2026. See THIRD-PARTY.md.
