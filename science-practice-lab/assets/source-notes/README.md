# Original image provenance and review notes

Create one short Markdown record per approved asset pack: creation date, description of source/original process, science/representation review, panel list and alt text, question IDs, crop details, and compression quality. Do not store paid exam screenshots or unapproved personal/student images.

Records should distinguish **generated illustrations** from **real documented photographs**. A synthetic satellite-like view, weather observation or experimental reading must be described as illustrative, not empirical evidence.
