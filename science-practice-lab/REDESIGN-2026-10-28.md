# Science Practice Lab: practice experience redesign

## Delivered scope

The shared question experience has been redesigned for all **306 original questions**, five units and nine response types. The work uses the teacher's twenty screenshots as an interaction and visual-quality reference. The app does not embed those screenshots or reproduce their questions or branded interface.

Students get a compact start panel, five-question quick practice, explicit response instructions, a consistent evidence/response workspace, numbered question navigation, flagging, skipping, an overview, intentional early completion, and a round focused on questions that needed another attempt. Unanswered ordering cards are distinguished from an intentionally submitted order.

Wrong-answer feedback supports another attempt before showing the solution. Correct responses show the explanation; hints and shown answers remain explicit actions. Test mode withholds feedback until completion. Multi-select questions require the stated number of distinct selections. One-to-one matching swaps occupied destinations; deliberate many-to-one matches and sorting keep their original behaviour. Choice order, dropdown alternatives and cards are mixed consistently within a round.

Teachers can filter by goal, response type, visual content and text; select questions; copy a student practice link; reveal teaching notes; and print a question set with an optional answer key. Preview interactions and teaching-note controls do not alter a student's saved round or progress. Practice links contain only a unit, question IDs and mode.

All original question IDs, scored answer keys, curriculum references and device storage keys remain. **68 questions** have direct content improvements: 8 Matter, 15 Energy, 18 Earth Systems, 19 Living Systems and 8 Space. Stems, misleading letter/number references, implausible distractors and dropdown alternatives have been revised where needed. For example, `collaboration-18` now asks how many years are missing **at least one** source, avoiding the ambiguity of saying the years “lack both sources.” Accurate scale diagrams continue to use code.

## Original artwork

Source: `assets/living/ecosystem-observations.png`; web asset: `assets/living/ecosystem-observations.webp`. Created with the built-in imagegen tool. No reference screenshot was supplied to the image generator. Four panels show a pond margin, mixed woodland, prairie grassland and dry North American desert. Artwork is identified as an illustration, not a field survey, numerical dataset or actual weather observation.

The source is 1536×1024. The complete four-panel web atlas is 1024×683 and 198,724 bytes, with a 220 KB exception budget because it supplies four separately cropped illustrations.

Generation brief: an edge-to-edge 2×2 atlas, four equal panels, detailed natural-history illustration, realistic organisms and plausible anatomy, no labels, arrows, text, watermarks or people. Wetland: reeds, cattails, frog, duck, water strider and dragonfly. Woodland: spruce, aspen, chickadee, deer, fungi, fallen leaves and log. Prairie: grasses, wildflowers, ground squirrel and bumblebee. Desert: sparse drought-adapted shrubs, cacti, rocky/sandy ground and a lizard. Full original generation text is retained in the originating conversation.

## Verification

The automated content suite checks every answer key and curriculum mapping, requested selection counts, stable choice mixing, matching replacement/swap semantics, original diagrams and storage identity. Existing full-bank browser workflows cover all five units and nine formats. The new browser regression suite checks teacher links, optional teaching notes, preserved student drafts, deferred test feedback, skipped ordering and printable packets.

Responsive release checks use 1366×650, 1024×540, 768×900, 390×667, 320×568 and 640×360, plus 125% layout zoom. The managed preview's live refresh returns to the start menu with the saved round available to resume.
