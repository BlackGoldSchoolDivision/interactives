The Basics

What is an Exponent?

An exponent is a shorthand way to write repeated multiplication.

base
exponent
23
2 × 2 × 2 = 8
  • The base is the number being multiplied.
  • The exponent (or power) tells you how many times to use the base as a factor.
  • Any non-zero number to the power of 0 is 1. (e.g., 50 = 1)
  • Any number to the power of 1 is itself. (e.g., 51 = 5)

How to Solve

To solve for a variable in an exponent equation, you usually need to isolate the variable or use opposite operations.

Solving for base (x² = 25)
Take the square root of both sides. x = 5 (or -5)
Solving for exponent (2ˣ = 8)
Ask: "2 to what power equals 8?" Since 2³ = 8, x = 3.
Note on Negative Roots
For even powers (like x²), there are technically positive and negative answers. For this activity, provide the positive answer.
