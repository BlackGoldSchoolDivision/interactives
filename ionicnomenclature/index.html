Chem 20: Ionic Nomenclature

Master the language of ionic compounds.

1
Binary Ionic Compounds

Compounds containing exactly two elements: a metal and a non-metal.

  • Cation (Metal): Write the full name of the metal.
  • Anion (Non-metal): Write the root name of the non-metal and change the ending to -ide.
Example: NaCl ➔ Sodium + Chlor(ine) ➔ Sodium chloride

2
Multivalent Metals

Transition metals (and some others like Pb, Sn) that can have more than one possible charge.

  • Determine the charge of the metal based on the non-metal's known charge.
  • Indicate the charge of the metal using a Roman numeral in parentheses immediately after the metal's name (no space).
Example: Fe2O3 ➔ O is -2 (total -6), so Fe must be +3 (total +6). ➔ Iron(III) oxide

3
Polyatomic Ions

Ions composed of more than one atom acting as a single charged unit.

  • Do not change the ending to -ide if the anion is polyatomic (e.g., use "sulfate", not "sulfide").
  • If more than one polyatomic ion is needed to balance the charge, place it in parentheses with the subscript outside.
Example: Ca(NO3)2 ➔ Calcium + Nitrate ➔ Calcium nitrate
