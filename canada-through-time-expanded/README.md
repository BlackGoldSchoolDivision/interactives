# Canada through time: homelands, colonies & Confederation

Separate expanded classroom edition. The original `territorial-evolution-canada/` app and its data are unchanged.

30 stops: before 1600, 1667, 1713, 1763, 1774, 1791, 1840/1841, plus the original 23 dates (1867–2003). Early views use published Atlas of Canada fourth-edition map panels with numbered place notes. The Act of Union view uses an explicitly dated 1849 reference map, not an exact 1841 snapshot. Before 1600 is modern geographic context without invented Indigenous polygons. For 1912–1998, a unified NWT label overlays the unchanged historical district colours and boundaries.

Each date offers Grade 4 and Grade 7 inquiry questions. These classroom connections are based on Colin Ward’s supplied KUSP excerpts, not a claim that the draft curriculum is final. Geography markers, keyboard navigation, timeline playback, side-by-side comparison, zoom, and accessible place lists are included.

Source links and map qualifications are available in the app’s Sources & data dialog and `data/sources.json`. Crop provenance is recorded in `data/crop-records.json`. Published early map panels retain the source resolution. The GeoJSON download remains available only for the 23 dates with actual vector data. All dependencies and maps are local; no analytics configuration is changed.

Serve this folder over HTTP. JavaScript is required. Responsive verification uses `screen-checks.html`, which embeds the same app in common classroom and phone viewport sizes.
