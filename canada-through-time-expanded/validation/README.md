# Validation

Run `npm install` and `npm test` in this directory. The jsdom tests execute the real app code against its local data, covering all 30 dates, source image existence, correct date labels and qualifications, place notes, Grade 4/7 prompts, vector boundaries, NWT district grouping, comparisons, previous boundaries, playback, keyboard navigation, and preserving date/selection/zoom on a resize event. `validation.txt` records the completed results. The JPEGs are rendered map previews, not browser screenshots.

Live browser checks completed on 2026-10-07 after authorized publication. `../screen-checks.html` passed all 30 dates and viewport checks at 1024×540, 1366×650, 768×900, 390×667, 320×568, 640×360 and 512×270 (a narrow/short zoom approximation). There was no page-wide horizontal overflow and tested controls met the 44px minimum. Resizing preserved the date, selected place and zoom; vector and colonial-source comparisons and the label toggle passed. Desktop and phone views, including the phone comparison dialog, were visually inspected. `live-preview-20261007.jpg` is a screenshot of the published 1713 view. The Lab catalog and original app remain unchanged.
