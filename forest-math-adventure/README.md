# Forest Math Adventure — illustrated review edition

Original counting activities created by **Chantelle**. The original forestmath1/ application is preserved unchanged.

New independent version: forest-math-adventure/.

## Play
Open on GitHub Pages or a static server. Pick one of five missions and answer five short rounds:
- Bear's Number Trail (forward ones)
- Owl's Backward Trail (backward ones)
- Squirrel's Big Hops (skip 2, 5 or 10)
- Woodland Patterns (missing number)
- Acorn Number Stories (addition / subtraction up to 20)

Includes optional browser speech synthesis, retries and hints, mouse/touch/keyboard controls, five-round feedback, no accounts or personal data. The illustrated photos and woodland artwork were cropped from the AI-generated concept design approved for this revamp and saved as **local raster WebP** files. UI and maths are real HTML/JS, no SVG or generated screenshot is passed off as a playable app.

No classroom hub replacement until review and approval. To validate mathematical generation: `node --test tests/*.test.mjs`.
