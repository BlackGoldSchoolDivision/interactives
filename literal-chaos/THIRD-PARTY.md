# Artwork and dependencies

Original code and original educational content created for Engaging Students / Black Gold School Division. Scene artwork generated for this project with OpenAI image generation, then cropped into transparent layers and compressed for delivery. Interface text remains live HTML.

- Nunito Sans regular and ExtraBold: SIL Open Font License; unchanged font files and notice in assets/Nunito-License.txt.
- jsPDF 4.2.1: MIT; bundled library and notice in vendor/JSPDF-LICENSE.txt.
- LadderPrint embedded print fonts: renamed ASCII subset of DejaVu Sans; original notice in vendor/PRINT-FONT-LICENSE.txt. Reused from the division's Word Ladders and Double Take apps.

No third-party network requests are needed for play or export. Device speech voices may vary. Ambient scene sound in Word Worlds is synthesized in the browser and starts only when the user enables it.
