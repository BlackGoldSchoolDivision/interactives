# Literal Chaos

A flat screen-print language game and an open-ended comic authoring lab.

Decode: 36 original contextual passages, 12 per flexible difficulty, covering 12 idioms and 6 each of simile, metaphor, hyperbole and personification. Filter by main teaching focus. Up to six questions per round with shuffled answer positions, retry scoring, contextual explanations and a collection.

Comic Lab: choose an expression, arrange and transform 12 illustrated props across independent literal/context panels, write captions, paraphrase, and explain what the figurative language adds. Hide the expression to invite a partner to infer it. Writing is not automatically graded. Download a two-panel PDF.

Teacher print practice: Letter or A4, unmarked student pages, optional separate answer keys. Make it my own produces a self-contained HTML with images, fonts, scripts and license notices embedded. App state stays in sessionStorage in the browser tab. No accounts, server calls for student writing, analytics or microphone.

The animation is a playful picture of words, not evidence of idiom origins. Teaching categories overlap; accept a defensible alternative classification. See TEACHER-NOTES.md.

Serve the repository as static files. Open `/literal-chaos/`. No build required. Shared cross-game checks live in `word-worlds/tools/` and run in the repository workflow `verify-language-playgrounds.yml`.

Created for Engaging Students / Black Gold School Division, October 2026. See THIRD-PARTY.md.
