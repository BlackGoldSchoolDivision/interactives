# Add the catalogue to Engaging Students

Catalogue URL: https://interactives.blackgold.ca/interactive-learning-lab/

1. Open the Engaging Students site in the Google Sites editor.
2. Select **Pages**. Hover over the **+** button, then choose **Full page embed**.
3. Name the page **Interactive Learning Lab**.
4. Paste the catalogue URL above and choose **Insert**.
5. Preview the page, then choose **Publish** to make the Google Sites change active.

The catalogue is also usable directly at its own URL. Its activity links open in a separate tab, so learners can return to the catalogue. Subsequent catalogue updates can appear at the same embed URL.

Google's instructions: https://support.google.com/sites/answer/90569?hl=en

The native Google Sites editor was not accessible in this session because its Google sign-in route returned a connection error. Publishing the catalogue does not itself create or publish the native Google Sites page.
